## Baggersee — notes
- Réel : ancienne gravière devenue plan d'eau (plage de sable, pelouses, volley, barbecue, parcours de santé en forêt), Illkirch-Graffenstaden ; centre commercial voisin collé à la rive ouest, en projet de transformation (strasbourg.eu, ZAC Baggersee).
- Pas de vraie marque d'enseigne dans le jeu : « BlingCo Lake Mall ».
- Mécaniques : nage avec endurance, plongée vers secrets/écharpes, bouées et pontons, coucher de soleil → nuit au passage vers le centre commercial.
- Absurde BlingCo : pompes qui vident le lac, arbres en plastique (creux, étiquette prix), maquette du projet à saboter dans le hall.
- À différencier du Port du Rhin (industriel + grappin) : Baggersee = nature + nage.

## Écharpes — règles (consigne : ludique, pas cassant pour le gameplay)
- **3 écharpes par niveau** : 1 sur le chemin principal, 1 derrière un raccourci ou un secret, 1 derrière un passage à objet (raison de revenir).
- **Récompense immédiate, sans effet sur l'équilibre** : chaque écharpe ramassée → un PNJ supporter à proximité lance un bout de chant + confettis/fumigène bleu.
- **3/3 dans un niveau** → l'écharpe complète s'accroche dans le menu de sélection (vignette) + un couplet du chant du kop débloqué (écoutable dans le menu).
- **Flèches bonus, plafonnées** : tous les 3 niveaux complétés à 3/3 → +1 flèche de capacité max. Plafond bas (≈ +3 sur le chapitre) pour ne jamais rendre un boss trivial. Jamais requises pour finir.
- **Toutes les écharpes du chapitre** → chant complet du kop, joué dans la scène de fin / place Kléber. Cosmétique uniquement.
- Aucune écharpe n'est perdue à la mort ; on peut les récupérer en rejouant un niveau.

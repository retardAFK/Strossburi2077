# docs/designs — fiches de design validées

Les designs de Stras 2067 sont travaillés par Maxime avec Claude (Cowork), puis déposés ici.
Claude Code n'intègre QUE les fiches au statut `validé` et n'invente aucune apparence.

Une fiche = `<nom>.md` (+ `<nom>.png` planche de référence, + éventuel `tools/blender/<nom>.py`).

## Modèle de fiche
```
# <Nom>
Statut : brouillon | validé (date, par Maxime)
Type : boss | ennemi | compagnon | arme | objet | PNJ | lieu
Rôle en jeu : ...
Silhouette : ...
Couleurs / matières : ...
Taille (par rapport à l'Ultra) : ...
Pivots / animation : ...
Contraintes gameplay : hitbox, point faible, ce qui doit se lire de loin
Ton : drôle / inquiétant / les deux
À éviter : ...
Citations de Maxime : « ... »
```

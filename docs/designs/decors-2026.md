# Décors 2026 validés (21/11/2026, par Maxime, dans Cowork)

Vignettes Blender low poly d'après les photos fournies par Maxime. Aucun logo, sponsor ni écusson réel ;
seuls les ajouts BlingCo (inventés) sont satiriques. Scripts dans `tools/blender/`.

**Ambiance Kléber (à reproduire en jeu)** : très sombre — façades quasi noires, fenêtres presque éteintes ; seuls les néons
et pubs BlingCo brillent. Planche assombrie en post-traitement ; en jeu : brouillard Three.js sombre violacé + éclairage
faible, émissif uniquement sur les néons/pubs. La satire vise BlingCo, jamais l'Alsace ni la cathédrale.
